# Roadmap

## Phase 1 - MVP
- FastAPI backend with dataset upload, profiling, and recipe endpoints
- React frontend shell with upload and table preview
- Docker Compose deployment

## Phase 2 - AI Integration
- AI-driven profiling and cleanup suggestions
- Context memory for business rules
- RAG workflows for user guidance

## Phase 3 - Advanced Analytics & UX
- Interactive dashboard builder
- Collaboration and sharing
- RBAC, SSO, audit logs

## Phase 4 - Extensibility & Automation
- Plugin/connector API
- Webhooks and scheduled jobs

## Phase 5 - Enterprise Hardening
- Compliance packs
- Hybrid/on-prem deployments
