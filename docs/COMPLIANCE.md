# Compliance & Enterprise Hardening

## Scope
This document outlines compliance-ready scaffolds for GDPR and SOC2.

## GDPR Readiness
- Data minimization: only required fields stored in metadata.
- Data portability: export endpoints planned.
- Right to erasure: deletion workflows planned.

## SOC2 Readiness
- Access controls: RBAC scaffolding implemented.
- Audit logging: middleware-based logging enabled.
- Change management: CI pipeline in place.

## Security Controls (Planned)
- Encryption at rest via managed databases.
- TLS termination via reverse proxy.
- Key rotation and secrets management via cloud KMS.
